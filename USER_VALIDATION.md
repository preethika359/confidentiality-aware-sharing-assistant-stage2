# User / Stakeholder Validation — Stage 2

## Validation protocol

A short stakeholder walkthrough should ask a faculty/admin reviewer to perform five tasks:

1. Open a PUBLIC policy as Student.
2. Attempt to open a CONFIDENTIAL disciplinary case as Student.
3. Request sharing of sensitive content.
4. Review the explanation evidence and policy rule.
5. Attempt a manual override and provide a rationale.

### Feedback questions

Rate 1–5:
- Was the access decision understandable?
- Was the explanation evidence useful?
- Did the system make the sharing boundary clear?
- Was the manual override safeguard appropriate?
- Would you trust this workflow for a pilot with synthetic data?

Open questions:
- What false positives would be most disruptive?
- Which university policy labels should be added?
- Which audit fields should administrators see?
